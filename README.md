# Original Whisper Server

This is the Whisper server for versions 1.x and 2.x of the [iOS/macOS client](https://github.com/whisper-project/client.ios). It is written in Javascript. The back end (that actually runs on the server) is in the back-end directory. The front end (that runs in the browser) is in the front end directory and is distributed from the back-end server.

There are some golang data maintenance utilities in the platform and cmd directories that are involved in migrating data from this server to the newer [Version 2 Server](https://github.com/whisper-project/whisper.server2) that will be used by the v3 iOS client.
